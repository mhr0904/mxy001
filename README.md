# 米小鱼每日信息候选池

这个仓库用于发布一个统一的每日信息候选池，而不是分别发布 X、即刻、知识星球、小宇宙、公众号的独立日报。

每日流程：

1. 从 5 个信源收集候选信息：X、即刻、知识星球、小宇宙、公众号。
2. 统一整理为 `data/today.json`。
3. 按主题、作者、关键词、置信度初筛并去重。
4. 运行 `python3 scripts/render_daily_pool.py` 生成 `index.html` 和 `today.md`。
5. 提交并推送到 GitHub Pages。

公开页面只放候选信息摘要，不放 Cookie、账号密码、客户信息、个人隐私、付费内容全文、私密社区全文或公众号全文。

公众号当前只支持手动接入：用户提供文章链接、标题、作者、少量摘录或复制内容后，由 Codex 整理进统一候选池。不要绕过登录、验证码、反爬或平台限制。
